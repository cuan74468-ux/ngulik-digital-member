# Keamanan Ngulik Digital Member

Laporkan kerentanan secara privat kepada pemilik repository melalui kanal kontak yang telah disepakati atau fitur **Private vulnerability reporting** pada GitHub bila tersedia. Jangan membuka issue publik yang mengandung rahasia, informasi akun member, PIN, token, nomor pelanggan, atau rincian eksploitasi.

Sertakan ringkasan dampak, langkah reproduksi minimal yang aman, dan file/versi terdampak **tanpa mengirim kredensial**. Jangan menguji pembayaran nyata, mengakses data pelanggan, atau mengubah lingkungan produksi tanpa izin tertulis pemilik.

Perbaikan keamanan dilakukan lewat Pull Request terpisah, pengujian otomatis, dan peninjauan pemilik. Commit source, deployment GitHub Pages, deployment Apps Script, dan verifikasi transaksi nyata adalah status yang berbeda.
